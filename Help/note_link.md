# Cách tạo link:

## 1. Bật GitHub Pages

Vào repository trên GitHub:

Settings → Pages

Ở phần Build and deployment:

Source: Deploy from a branch
Branch: main
Folder: / (root)
Nhấn Save

Sau một lúc GitHub sẽ tạo website tại:

https://anhjob.github.io/bai_giang_tin_hoc_2627/

## 2. Cách chuyển Private → Public

Mở repository trên GitHub.
Chọn Settings.
Kéo xuống phần Danger Zone.
Tìm Change repository visibility.
Chọn Change visibility.
Chọn Public.
Xác nhận repository và chọn Make this repository Public.

* Nếu tài khoản của bạn đang dùng GitHub Free, repository phải để Public thì mới dùng GitHub Pages được. GitHub xác nhận GitHub Pages trên Free chỉ hỗ trợ repository public.
